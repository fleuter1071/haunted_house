# Asset Pipeline

Store game art assets here by gameplay role.

- `characters/`: player and friendly character sprites
- `enemies/`: ghost, experiment, and enemy sprites
- `props/`: doors, shelves, candles, portraits, machines, keys, and other objects
- `rooms/`: room backgrounds or large environmental art
- `ui/`: HUD, buttons, icons, and overlays

Preferred first format: SVG for editable geometric spooky art. Use PNG when raster detail, texture, or generated art is needed.
